# 🤖 Autonomous Robotics & Automation System
**University of Sheffield**
 
## Overview
An autonomous robot built for two main tasks: **line-following navigation** and **robotic arm manipulation** (including drawing). The chassis was laser-cut from wood, with selected arm components 3D-printed for precision. The system was programmed using Arduino and controlled via custom C++ firmware.
 
## Hardware
| Component | Details |
|---|---|
| Chassis | Laser-cut wood |
| Arm Parts | 3D-printed |
| Microcontroller | Arduino |
| Actuators | DC motors + servo motors |
| Sensors | IR sensors for line detection |
 
## Software & Tools
- **C++** — motor control, sensor logic, arm sequencing
- **MATLAB** — control system analysis and PID tuning
- **Autodesk Fusion 360** — part design for 3D-printed components
## Features
- **Line Following** — real-time IR sensor feedback with PID-based motor correction
- **Robotic Arm** — servo-controlled arm performing precision tasks (e.g., drawing)
